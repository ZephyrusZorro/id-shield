# Deploying ID-SHIELD Online

The same codebase that runs offline deploys unchanged — the container serves
the built UI **and** the API on one port. Pick one of the options below; all
of them can be free-tier friendly.

> Reminder: the prototype has no authentication. If you expose it publicly,
> put it behind your own access control (e.g. Cloudflare Access, a reverse
> proxy with basic auth) and remember uploads are stored on the host.

---

## Option A — Render (easiest, Docker)

1. Push this repository to GitHub.
2. On https://render.com → **New → Web Service** → connect the repo.
3. Runtime: **Docker** (Render detects the `Dockerfile`).
4. Instance: Free tier is fine for demos.
5. Environment variable (optional): none required; defaults work.
6. **Create Web Service** → first build ~3-4 min (installs Tesseract).
7. Your URL: `https://<service>.onrender.com`.

Persistence note: free instances have ephemeral disk — uploaded cases reset on
redeploy. For durable storage attach a Render Disk mounted at
`/app/backend/data` or switch to Postgres (Option D).

## Option B — Fly.io

```bash
fly launch --no-deploy            # detect Dockerfile, choose region
fly volumes create idshield --size 1   # persistent uploads/DB
fly deploy
```

`fly.toml` generated by `fly launch` needs:

```toml
[env]
  PORT = "8080"
[[http_service]]
  internal_port = 8080
  force_https = true
[mounts]
  source = "idshield"
  destination = "/app/backend/data"
```

## Option C — Hugging Face Spaces (Docker)

1. Create a Space → SDK: **Docker**.
2. Push repo files (Space secrets not needed).
3. In `README.md` of the Space set: `app_port: 7860`, and start command uses
   `$PORT` — already supported by the container CMD.

## Option D — Any VPS / your own server

```bash
docker compose up --build -d              # SQLite + persistent volume
# or with PostgreSQL:
docker compose --profile postgres up --build -d
```

Then point Nginx/Caddy at `http://127.0.0.1:8000` for TLS.

To use Postgres from the app container:

```
DATABASE_URL=postgresql+psycopg2://idshield:idshield@db:5432/idshield
```

(`psycopg2-binary` may be added to requirements when choosing this path.)

## Environment variables

| Variable | Default | Notes |
|---|---|---|
| `DATABASE_URL` | SQLite file | PostgreSQL-compatible |
| `UPLOAD_DIR` | `./data/uploads` | mount a volume for persistence |
| `CORS_ORIGINS` | localhost:5173 | comma-separated; empty = same-origin only |
| `MAX_UPLOAD_MB` | 10 | per-file cap |
| `LOG_LEVEL` | INFO | DEBUG/WARNING/ERROR |

## Health check

`GET /api/health` → `{"status":"ok",...}` — use it as platform probe.
